Ação Necessária: Corrija as Coordenadas

Os dados GeoJSON carregados não estão no sistema de coordenadas correto (WGS 84). Para visualizar o mapa, siga o guia no QGIS para reprojetar a camada para EPSG:4326 e cole o novo conteúdo no arquivo da pasta data/.
