Ações recomendadas por classe

    Guia do Estudante: como publicar uma nova camada

    Não é preciso saber programar. Você vai exportar o arquivo do QGIS, colocar na pasta certa e cadastrar uma linha no arquivo de configuração.

    1. 1. Exporte o GeoJSON no QGIS

      • No painel de camadas, clique com o botão direito na camada e vá em Exportar > Salvar feições como...
      • Formato: GeoJSON.
      • SRC: EPSG:4326 - WGS 84. Esse passo é obrigatório; em outro sistema o site não consegue desenhar a camada e mostra um aviso.
      • Use nomes de arquivo sem espaços nem acentos, por exemplo diadema_suscetibilidade.geojson.
      • Confira os nomes das colunas. O padrão do laboratório é municipio, is_valor, classe_estabilidade, grau_risco e populacao para a suscetibilidade, e id, nome, tipo, municipio, endereco e fonte para os equipamentos.

    2. 2. Coloque o arquivo na pasta data/

      • Suscetibilidade geológica: data/geologico/
      • Equipamentos públicos (pontos): substitua data/equipamentos_publicos.geojson
      • Pelo GitHub na web: abra a pasta, clique em Add file > Upload files e arraste o arquivo.

    3. 3. Cadastre a camada em js/config.js

      Copie um bloco existente da lista camadas e troque os valores:

      {
    id: 'mairipora_suscetibilidade',        // nome único, sem espaços
    nome: 'Suscetibilidade a escorregamentos',
    arquivo: 'data/geologico/mairipora_suscetibilidade.geojson',
    municipio: null,                        // ou o nome, se a camada não tiver coluna de município
    campoMunicipio: 'municipio',            // coluna com o município
    campoClasse: 'classe_estabilidade',     // "S1: Estável", "S2: Pouco Estável" ou "S3: Instável"
    campoIS: 'is_valor',                    // Índice de Suscetibilidade (1,0 a 5,0)
    campoGrau: 'grau_risco',                // "Baixo", "Moderado", "Alto"...
    campoPopulacao: 'populacao'             // população residente (IBGE)
},

      Se uma coluna não existir no seu arquivo, escreva null. Sem a classe, o site calcula S1, S2 ou S3 a partir do is_valor; sem os dois, usa o grau_risco. A nova camada aparece sozinha no seletor de município, na legenda e na aba Gestão.

    4. 4. Teste antes de publicar

      • O navegador não lê arquivos GeoJSON quando o index.html é aberto com dois cliques. Teste por um servidor local:
      • VS Code: instale a extensão Live Server e clique em Go Live.
      • Terminal: na pasta do projeto rode python -m http.server e abra http://localhost:8000.
      • GitHub Codespaces: rode o mesmo comando e abra a porta 8000 que aparece.
      • Se algo der errado, um aviso amarelo aparece no topo do site dizendo qual arquivo falhou.

    5. 5. Publique

      Faça o commit no GitHub. O GitHub Pages atualiza o site em poucos minutos.

    Metodologia de mapeamento (Soares Jr. et al., 2022)

    As cartas seguem a Combinação Qualitativa de Mapas por Matriz Multicritérios e Pesos. O Índice de Suscetibilidade de cada unidade é IS = Σ (Ri × Pij), em que Ri é o grau (1 a 5) de cada fator e Pij o seu peso:

    Fator condicionantePeso
    Declividade40%
    Litologia20%
    Uso e ocupação do solo20%
    Curvatura vertical (morfologia)10%
    Densidade de lineamentos estruturais10%

    O IS é agrupado em três classes consolidadas (Crozier, 1986 / GeoMAPA), as mesmas usadas no mapa e na aba Gestão:

    • S1: Estável (IS < 2,99): graus Muito Baixo e Baixo.
    • S2: Pouco Estável (2,99 ≤ IS < 3,53): grau Moderado.
    • S3: Instável (IS ≥ 3,53): graus Alto e Muito Alto.
